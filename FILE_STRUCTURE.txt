   - checkTokenBucket()       : Token bucket algorithm

   Key features:

LOAD BALANCER SERVICE:
──────────────────────

load-balancer/main.go (12.2 KB, ~600 lines)
   Smart load balancing with least-load strategy
   Functions:
   - assignBasedOnLoad()      : Least-load assignment
   - loadBalanceHandler()     : Request handler
   - checkBackendLoad()       : Health check
   - startLoadChecker()       : Periodic health checks
   - routeWithFailover()      : Failover logic
   - logRequest()             : Request logging
   Key features:
   - Sticky routing (per-cookie)
   - Health checks every 3 seconds
   - Automatic failover
   - Load caching in Redis
   - Request logging per backend

   Multi-stage build for Go binary
